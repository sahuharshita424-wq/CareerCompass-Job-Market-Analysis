# CareerCompass – Job Market Intelligence & Skill Gap Analysis

## Project Overview
CareerCompass is an Excel-based data analytics project designed to analyze job market trends, salary patterns, hiring insights, and candidate skill gaps.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Interactive Dashboard
- Slicers and Filters

## Key Features
- Analysis of job roles and locations
- Salary trend analysis
- Work mode and experience-level analysis
- Application status tracking
- KPI dashboard for jobs, applications, offers, and average salary
- Candidate skill gap analysis

## Dataset
This project uses a 5,000-row synthetic dataset created for educational and analytical purposes. It does not represent verified real-world job market data.

## Project Objective
To transform raw job market data into meaningful insights through Excel data analysis and interactive visualizations.
